Morison Load Calculation on Offshore pile¶

Objective¶

In this notebook, we will calculate the hydrodynamic wave load acting on a vertical offshore monopile using the Morison Equation.

The example problem is:

  • Monopile Diameter = 1.6 m
  • Water Depth = 30 m
  • Wave Height = 6 m
  • Wave Period = 10 sec
  • Water Density = 1025 kg/m³

The pile is divided into multiple vertical segments and the force on each segment is calculated individually.

Physical Understanding¶

When waves pass an offshore structure:

  • Water particles move horizontally and vertically
  • These moving particles create:
    • Drag Force
    • Inertia Force

The total force is calculated using the Morison Equation.

Deep Water Wave Length¶

For deep water condition:

$$ L = \frac{gT^2}{2\pi} $$

Where:

  • $L$ = Wave length
  • $g$ = Gravitational acceleration
  • $T$ = Wave period

Wave Number¶

$$ k = \frac{2\pi}{L} $$

Wave number defines how rapidly the wave oscillates spatially.

Angular Frequency¶

$$ \omega = \frac{2\pi}{T} $$

Angular frequency defines how rapidly the wave oscillates in time.

Morison Equation¶

The inline hydrodynamic force per unit length is:

$$ F = \frac{1}{2} C_d \rho D u|u| + C_m \rho \frac{\pi D^2}{4} a $$

Horizontal Water Particle Velocity¶

$$ u = \frac{ 0.5 H \omega \cosh(k(d+y)) }{ \cosh(kd) } \cos(\theta) $$

Horizontal Water Particle Acceleration¶

$$ a = - \frac{ 0.5 H \omega^2 \cosh(k(d+y)) }{ \cosh(kd) } \sin(\theta) $$¶

# ---------------------------------------------------
# Water Particle Velocity and Acceleration
# ---------------------------------------------------

# Horizontal particle velocity
u = (
    (0.5 * H * omega *
     np.cosh(k * (d + y)))
    / np.cosh(k * d)
) * np.cos(theta)

# Horizontal particle acceleration
a = -(
    (0.5 * H * omega**2 *
     np.cosh(k * (d + y)))
    / np.cosh(k * d)
) * np.sin(theta)

# Print values
for i in range(len(y)):

    print(f"Velocity = {u[i]:8.4f} m/s")
    print(f"Acceleration = {a[i]:8.4f} m/s2")
    print("-"*40)

Engineering Interpretation¶

From the plots we can observe:

  • Wave-induced motion is highest near the free surface
  • Motion decreases with depth
  • Acceleration dominates near wave crest/trough phases
  • Offshore structures experience non-uniform loading over depth

This depth-varying behavior is very important in:

  • Offshore wind monopiles
  • Jacket structures
  • Risers
  • Subsea pipelines
  • Offshore platforms

# ---------------------------------------------------
# SECTION 4 — Morison Force Calculation
# ---------------------------------------------------

# Drag force per unit length (kN/m)
Fd = (
    0.5
    * Cd
    * rho
    * D
    * u
    * np.abs(u)
) / 1000

# Inertia force per unit length (kN/m)
Fi = (
    Cm
    * rho
    * (np.pi * D**2 / 4)
    * a
) / 1000

# Total force per unit length (kN/m)
Ft = Fd + Fi
