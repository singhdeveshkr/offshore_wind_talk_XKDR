# Statistical Wave Modelling

This repository contains an interactive HTML visualization of stochastic ocean wave modelling based on transformed Gaussian processes and spectral wave analysis.

Topics covered:
- Wave time series
- Spectral density
- Crossing intensity
- Extreme wave prediction
- Non-Gaussian wave behaviour

This model is intended only for understanding the methodology and concepts presented in the offshore wind engineering talk.

For actual offshore design, hydrodynamic analysis, and realistic sea state modelling, industry standards and recommended practices should be followed, including:

- DNV-RP-C205 — Environmental Conditions and Environmental Loads
- DNV-ST-0437 — Loads and Site Conditions for Wind Turbines
- API RP 2A-WSD — Planning, Designing and Constructing Fixed Offshore Platforms
- IEC 61400-3 — Design Requirements for Offshore Wind Turbines

Developed for educational and visualization purposes related to offshore wind and ocean engineering.
